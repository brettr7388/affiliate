- [ ] Test all features work properly
- [ ] Clear browser cache and cookies

- [ ] Have admin token ready: `demo-admin-token-2025`
- [ ] Prepare sample Amazon product URLs
- [ ] Review demo script and key talking points
- [ ] Practice the flow 2-3 times
- [ ] Prepare backup content in case of errors

### ✅ Environment Setup
- [ ] Use a clean, uncluttered desktop
- [ ] Close all personal tabs and applications
- [ ] Set browser to full-screen mode
- [ ] Ensure good lighting for webcam (if using)
- [ ] Test recording area for background noise

## 🎬 Recording Tips

### Screen Recording Best Practices
1. **Resolution**: Record at 1920x1080 for best quality
2. **Frame Rate**: 30 FPS is sufficient for demo videos
3. **Audio**: Use a good microphone, avoid laptop built-in mic
4. **Browser**: Use Chrome or Safari for best compatibility
5. **Zoom**: Keep browser zoom at 100% for consistency

### Narration Guidelines
1. **Speak Clearly**: Enunciate and speak at moderate pace
2. **Be Enthusiastic**: Show excitement about the features
3. **Explain Benefits**: Don't just show features, explain why they matter
4. **Use "You" Language**: "You can create..." instead of "The system can..."
5. **Avoid "Um" and "Uh"**: Practice smooth transitions

### Visual Guidelines
1. **Mouse Movement**: Move cursor smoothly, avoid rapid movements
2. **Click Timing**: Pause briefly after clicks to show results
3. **Scroll Speed**: Scroll slowly to allow viewers to read
4. **Highlighting**: Use cursor to point out important elements
5. **Transitions**: Pause between major sections

## 🛠️ Troubleshooting Tips

### Common Issues & Solutions
1. **Slow Loading**: Refresh page, check internet connection
2. **Login Issues**: Double-check admin token
3. **Missing Data**: Run demo_setup.py again
4. **Audio Issues**: Test microphone before recording
5. **Browser Crashes**: Keep backup browser ready

### Backup Plans
- Have screenshots ready for key features
- Prepare offline demo data
- Know how to quickly restart the application
- Have alternative product URLs ready
