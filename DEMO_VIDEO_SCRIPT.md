## 🎥 HeyGen Setup Instructions

### **Screen Recording for HeyGen**
- **Resolution**: 1920x1080 (Full HD)
- **Frame Rate**: 30 FPS
- **Duration**: 3-4 minutes total
- **Browser**: Use Chrome or Safari for best compatibility
- **No Audio**: HeyGen will add AI voiceover

### **HeyGen Text Overlay Setup**
- **Font**: Modern, clean sans-serif
- **Color**: White text with dark outline for visibility
- **Position**: Top-center or bottom-center
- **Timing**: Appear for 3-4 seconds each
- **Animation**: Fade in/out smoothly

### **Preparation Checklist**
- [ ] Start the application: `python start_admin.py`
- [ ] Have admin token ready: `demo-admin-token-2025`
- [ ] Prepare sample Amazon product URLs
- [ ] Clear browser cache for clean demo
- [ ] Test all features beforehand
- [ ] Record screen without audio (HeyGen adds voice)

### **Demo Environment Setup**
1. **Start the server**: `python start_admin.py`
2. **Use admin token**: `demo-admin-token-2025`
3. **Open browser** to `http://127.0.0.1:8088`
4. **Prepare sample data**:
   - Existing routes (6 demo routes)
