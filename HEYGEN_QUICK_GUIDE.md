## 🤖 HeyGen Setup

### **Upload to HeyGen**
1. Upload your screen recording
2. Add AI voiceover
3. Add text overlays from the list above
4. Set timing for each overlay
5. Export as MP4

### **Text Overlay Settings**
- **Font**: Modern sans-serif
- **Color**: White with dark outline
- **Position**: Top-center or bottom-center
- **Duration**: 3-4 seconds each
- **Animation**: Fade in/out
