# 🚀 Quick Demo Start Guide

## Get Your Demo Running in 5 Minutes

### Step 1: Setup Demo Environment
```bash
# Run the demo setup script
python demo_setup.py
```

This will:
- ✅ Create sample affiliate routes
- ✅ Generate demo content and articles
- ✅ Add sample click data for analytics
- ✅ Set up demo subscribers
- ✅ Configure environment variables

### Step 2: Start the Application
```bash
# Start the server
python start_admin.py
```

**Note the admin token displayed in the terminal!**

### Step 3: Access the Demo
- **Homepage**: http://127.0.0.1:8088
- **Admin Console**: http://127.0.0.1:8088/admin
- **Admin Token**: `demo-admin-token-2025`

### Step 4: Demo Features to Show

#### 🏠 Homepage Features
- Beautiful eco-friendly design
- Dynamic article loading
- Product comparison tables
- Newsletter signup
- Live footer statistics

#### ⚙️ Admin Console Features
- Real-time dashboard
- Affiliate route management
- AI content generation
- Image generation
- Analytics and reporting
- Article management

#### 🔗 Affiliate Link Demo
1. Go to admin → Routes
2. Create new route: `demo-product-2025`

#### 🤖 AI Content Generation Demo

## 🛠️ Troubleshooting

### Common Issues
- **Slow loading**: Refresh browser, check internet
- **Login issues**: Use token `demo-admin-token-2025`
- **Missing data**: Run `python demo_setup.py` again
- **Port conflicts**: Try `python start_admin.py --port 8089`

### Backup Plans
- Have screenshots ready
- Know how to restart quickly
- Keep alternative product URLs handy
